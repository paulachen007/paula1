# paula1

🔮 **塔罗占卜** —— 心里默念一个问题，抽一张牌。

## 在线玩

👉 **https://paulachen007.github.io/paula1/**

手机浏览器直接打开就能玩，不用安装任何东西、不用下载 App。

## 玩法

1. 在心里默念你的问题（也可以写进输入框）
2. 点「抽一张牌」
3. 系统从 **22 张大阿卡纳** 中随机抽一张，并随机判定 **正位 / 逆位**
4. 牌面会相应变化（逆位时倒转显示），并给出这张牌对你问题的解读

> 逆位概率 35%，正位 65%。

## 技术说明

- **单文件**：整个游戏就在 `index.html` 里，零外部依赖、断网也能玩
- **移动端优先**：适配 iPhone 刘海安全区，输入框字号 ≥16px（避免 iOS 自动放大），按钮触摸区域 ≥52px
- **无追踪**：没有引入任何统计、广告或第三方脚本

## 本地运行

```bash
git clone https://github.com/paulachen007/paula1.git
cd paula1
open index.html        # macOS 直接打开
```
