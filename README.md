这是一个 **PWA**，不装 App Store 也能像 App 一样使用：独立图标、全屏无地址栏、**断网也能打开**。

## 玩法

1. 写下你的问题（例如「我这次考试能过吗？」）
2. 系统自动识别问题属于哪个话题：💗感情 / 💼事业 / 📚学业 / 💰财运 / 🤝人际 / 🌿健康
   - 识别不准可以**手动点选**，保证答案一定对得上
3. 点「抽一张牌」，从 22 张大阿卡纳中随机抽一张，随机判定正位 / 逆位
4. **答案直接写在牌面上**，牌下方给出这张牌本身的牌意

## 界面

- **近黑底 + 亮暖金**，衬线字体，星空与星座连线背景
- 牌背是缓慢旋转的曼陀罗纹样 + 金色四角星
- **正位**用金色、**逆位**用紫色描边与牌名区分（逆位不会把文字转过去，保证可读）
- 底部输入条固定悬浮，小屏也能随时提问
- 适配 iPhone 刘海安全区，支持「减少动态效果」系统设置

答案只从「对应话题 + 对应正逆位」的库里抽取，所以**问题和答案永远对得上**。

## 技术说明

- **单文件**：整个游戏就在 `index.html` 里，零外部依赖、无追踪脚本
- **话题识别**：关键词计分匹配，长关键词权重更高（「考研」比「考」更有决定性）；识别不出时回退到「通用」
- **PWA**：`manifest.json` + `sw.js`，Service Worker 离线缓存；导航请求网络优先，保证能拿到最新版
- **图标**：`icons/` 下 5 个尺寸，含 maskable 版本（Android 自适应图标）

## 本地运行

```bash
git clone https://github.com/paulachen007/paula1.git
cd paula1
open index.html        # macOS 直接打开
```

> 注意：Service Worker 需要 HTTPS 或 localhost 才能生效，直接双击本地文件时离线功能不可用（页面本身正常）。

## 项目结构

```
index.html          # 游戏本体（HTML + CSS + JS 全在这一个文件）
manifest.json       # PWA 清单：名称、图标、主题色、独立窗口
sw.js               # Service Worker：离线缓存
icons/              # 应用图标（192 / 512 / maskable / apple-touch / favicon）
preview.png         # 界面预览图
qr.png              # 在线地址二维码
```
