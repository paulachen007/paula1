## 玩法

1. 写下你的问题（例如「我这次考试能过吗？」）
2. 系统自动识别问题属于哪个话题：💗感情 / 💼事业 / 📚学业 / 💰财运 / 🤝人际 / 🌿健康
   - 识别不准可以**手动点选**，保证答案一定对得上
3. 点「抽一张牌」
4. 从 22 张大阿卡纳中随机抽一张，随机判定正位 / 逆位（逆位概率 35%）
5. 给出**两层解读**：
   - **牌面** —— 这张牌本身的气质与牌意
   - **🎯 针对你的问题** —— 从该话题的答案库里随机抽一条

## 答案库

答案按话题分开，每个话题各有独立的**正位库**和**逆位库**：

| 话题 | 正位 | 逆位 |
|:--|--:|--:|
| 💗 感情 | 16 | 16 |
| 💼 事业 | 16 | 16 |
| 📚 学业 | 16 | 16 |
| 💰 财运 | 16 | 16 |
| 🤝 人际 | 16 | 16 |
| 🌿 健康 | 16 | 16 |
| ✨ 通用 | 20 | 20 |
| **合计** | | **232 条** |

答案只从「对应话题 + 对应正逆位」的库里抽取，所以**问题和答案永远对得上**。

## 技术说明

- **单文件**：整个游戏就在 `index.html` 里，零外部依赖、断网也能玩
- **话题识别**：关键词计分匹配，长关键词权重更高（「考研」比「考」更有决定性）；识别不出时回退到「通用」
- **移动端优先**：适配 iPhone 刘海安全区，输入框字号 ≥16px（避免 iOS 自动放大），按钮触摸区域 ≥52px
- **无追踪**：没有引入任何统计、广告或第三方脚本
